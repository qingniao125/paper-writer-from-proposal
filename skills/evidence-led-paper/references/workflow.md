# 可复用学术论文工作流

固定主流程、论文类型分支与阶段验收相结合。适用于新写、重构、修订和投稿准备。本文为 evidence-led-paper 技能的完整方法参考；不表示仓库其他脚本已经过验证。

## 下次调用

把下面提示和本文件一起交给助手，或指定本文件完整路径：

> 请读取并按《可复用学术论文工作流》v1.0执行。研究主题：〔填写〕；任务模式：〔新写／重构／局部修订／投稿准备〕；材料位置：〔填写〕；目标期刊：〔填写或待定〕；交付形式与篇幅：〔填写〕。先检查现有材料、已有进度和证据缺口，建立研究任务单、论点与证据台账、修订与验收记录。已完成且未变动的步骤不重复。重大方向变化先与我对齐，已授权范围内的常规工作连续推进。保留原稿，输出带日期时间的新版本，明确各项核验状态。

调用位置不限定为申报书；田野材料、图像、档案、数据、提纲和已有论文均可作为起点。

## 一 固定主流程

| 阶段 | 工作 | 产物 | 通过条件 |
| --- | --- | --- | --- |
| 1 明确任务 | 确认对象、问题、已有材料、期刊、篇幅、交付形式 | 研究任务单 | 问题具体，范围可控，材料与目标相匹配 |
| 2 整理材料 | 清点原稿、版本、图像、访谈、档案、数据与文献 | 材料清单和缺项清单 | 关键材料可追溯，未知信息已标出 |
| 3 检索核验 | 围绕具体问题检索，阅读原文，核对书目信息和论证支持 | 文献库和证据台账 | 核心主张有支持，或明确补充研究任务 |
| 4 设计论证 | 串联研究现状、问题、主张、证据和替代解释 | 论证提纲 | 各节任务独立，合起来回答核心问题 |
| 5 撰写初稿 | 按论证单元写作，随写记录来源，据正文形成摘要与结论 | 完整初稿 | 主张有依据，缺口有标记，章节衔接 |
| 6 分轮修订 | 依次学术修订、结构修订、语言修订 | 修订稿和处理记录 | 重大问题已处理，推论范围适当 |
| 7 期刊适配 | 标题摘要、引文图表、作者与匿名信息、附件 | 投稿候选稿 | 符合明确要求，各附件信息一致 |
| 8 验收归档 | 核查内容、结构、文件完整性和所有页面 | 交付稿、验收记录、归档包 | 必要检查通过，残余问题清楚列明 |

流程允许回返：补证失败返回问题或论证设计；图像识别改变时复查正文、摘要和结论；每次实质修改后复核受影响的引用与页面。

## 二 三份贯穿全程的记录

### 研究任务单

记录研究对象、核心问题、预期贡献、材料范围、论文类型、研究方法、目标期刊、篇幅、交付形式、不纳入的内容、原稿版本、当前阶段及待作者决定事项。贡献先作为待检验主张，不预先宣布成立。

### 论点与证据台账

每个重要判断记录：编号、判断内容、来源、证据类型、版本、原文或图像定位、支持程度、推理过程、限制、替代解释、正文位置、核验状态。书目真实与支撑判断分别检查。

核验状态：已核实／字段待纠正／明确错误／证据不足。未见全文应明示；摘要只支持其明确表述。访谈元数据齐备不能代替原始记录核验。

### 修订与验收记录

记录版本、位置、问题、严重程度、处理方式、核验依据、当前状态和下一步。问题状态为待处理／已修改／已复核。跨版本保留记录，不将旧版本通过状态自动复制给新版本。

## 三 论文类型分支

| 类型 | 额外检查 |
| --- | --- |
| 图像、器物、艺术史 | 身份、年代、版本、收藏与图源、摄影条件、比较维度、历史关系证据 |
| 田野与非遗 | 受访者身份、时间地点、原始记录、访谈语境、同意授权、整理方式、研究者位置 |
| 历史文献 | 版本辨析、成文语境、异文、来源独立性与相互印证 |
| 实证研究 | 研究设计、样本、测量、数据处理、分析、适当的稳健性与可重复性检查 |
| 文献综述 | 综述类型、检索范围与检索式、纳入排除标准、筛选记录、综合方法 |
| 理论研究 | 概念、前提、推理链、反例、替代解释、适用范围 |

可组合分支，但应明确每类材料的证明任务。申报书中的拟开展工作不能写成已经完成的研究或结果。

## 四 证据与写作标准

1. 重要判断有明确材料落点；区分观察、引文、口述、分析与推论。
2. 形态相似不能单独证明传播方向；单一样本不能直接代表整个地区。
3. 艺人经验估计不转写为统计结论。供图人、制作者、受访者分别登记。
4. 原始引语、地方称谓和版本异文保留原貌；整理、转述、合并引语交代处理方式。
5. 引用按实际阅读版本著录；不将不同版本页码混用。
6. 不补造文献、数据、页码、访谈信息或授权。检索无结果不等于材料不存在。
7. 优先使用适合学科和材料类型的来源，不将单一数据库设为所有论文的必经入口。
8. Zotero可用于管理来源；工具不可用时记录限制，以可追溯台账继续工作，不虚称已导入或已生成动态引文字段。
9. 不为扩写堆砌概念。扩写依靠新材料、细节、比较与解释。
10. 语言修订保留原意、事实与必要限定；不能把作者假设润色成确定事实。

## 五 三轮修订

1. 学术修订：核实事实与材料，检查概念、贡献、推论边界、反例和替代解释。
2. 结构修订：检查章节任务、段落次序、重复内容和论证缺环。
3. 语言修订：修正主语、指代、语序、术语、引语、冗句及表达风格。

短句比例、禁用词、图片排列、理论密度等列为单篇配置，不作为普遍规则。作者风格校准须基于实际语料，不移用他人的事实、经验或独特表达。

## 六 引用与期刊规则

依据顺序：目标期刊明确要求 → 编辑部具体反馈 → 刊物样稿 → 通用规范 → 项目内部偏好。冲突需记录，样稿不能推翻明确要求。

- 正文引文、脚注、文末参考文献、图注及图片来源分工清楚。
- 同一来源再次支持新的判断时再次引用，顺序编码制沿用原编号；页码按对应位置和刊物要求提供。
- 默认每条独立文献对应独立条目；特殊编排需有明确依据。
- 多条来源确实共同支持同一句判断时可同时引用，不机械限制为一个引文号。
- 脚注编号方式按目标刊要求配置，不能固定为逐页重启。
- 格式整理与真实性核验分别记录。
- 图源、图片授权和分辨率分别检查；不将低清图伪称为高清。
- 图像分析正文必须指出相关图号；图注保留识别信息。
- 作者资料、基金、英文信息和投稿信与主稿一致；签字、提交和联系编辑部需实际授权。

## 七 验收与状态

| 层次 | 验收问题 |
| --- | --- |
| 材料 | 来源、版本、记录、图片及权限是否可追溯 |
| 论证 | 证据是否支持判断，范围是否适当 |
| 编辑 | 语言、术语、摘要、结论、中英文信息是否一致 |
| 结构 | 引文、脚注、图号、参考文献是否对应 |
| 文件 | 文件是否可打开，结构与完整性是否正常 |
| 视觉 | 最新版每页字体、图片、表格、分页、脚注是否清晰 |
| 投稿 | 要求及附件是否核对齐备 |

文件生成、结构通过、PDF生成、逐页视觉通过必须分别报告。中文方框、乱码或裁切未解决时，不能称视觉通过。必要资料和授权缺失时不能称可投稿。

状态：研究稿（可有显式缺口）→ 审阅稿（正文完整供审读）→ 投稿候选稿（适配验收中）→ 可投稿稿（必要检查全部通过）。可投稿不表示录用。

## 八 项目组织与协作

建议每篇新建独立目录：

- 00_研究任务单.md
- 01_材料清单.md
- 02_论点与证据台账.md
- 03_论证提纲.md
- 04_修订与验收记录.md
- sources/ 原始材料
- drafts/ 修订版本
- outputs/ 交付文件

保留原稿，新稿按“短题名_阶段_YYYYMMDD_HHMMSS”命名。已授权的常规核验、局部修改、编号和版面修复连续推进。研究对象、证据范围或核心方向发生重大变化时再对齐。每轮简报：解决事项、未决事项、下一步。不得自动发送邮件、提交论文或签署协议。

## 九 维护

本版来源于多轮论文写作协作经验，已剔除特定作者、未发表材料和私人联系方式。用于新项目时重新核实刊物要求。此文件仅定义流程，不证明仓库既有脚本、示例或文献已经验证。后续修改增加版本号和变更摘要；不静默覆盖单篇已确认的要求。
