# 论文结构模板

## 标准学术论文结构

### 通用结构（适用于课程论文/项目结项/期刊发表）

```
一、问题提出
   ├── （一）研究背景
   ├── （二）研究问题
   └── （三）研究意义

二、文献基础
   ├── （一）理论框架
   ├── （二）国内外研究现状
   └── （三）研究述评

三、方案展开/研究方法
   ├── （一）研究框架/总体思路
   ├── （二）研究内容/技术路线
   └── （三）创新点/关键技术

四、可验证应用场景/实验验证
   ├── 场景一：xxx
   ├── 场景二：xxx
   └── 场景三：xxx

五、结语
   ├── （一）研究结论
   ├── （二）研究局限与展望
   └── 基金致谢
```

## 期刊论文变体

### 简短版（6000-8000字）

```
1. 引言/前言
2. 相关工作/文献综述
3. 方法/方案
4. 实验/应用
5. 结论
```

### 完整版（8000-15000字）

```
1. 摘要
2. 关键词
3. 引言
4. 相关研究与理论基础
5. 研究方法与设计
6. 研究过程
7. 结果与分析
8. 讨论
9. 结论与展望
10. 参考文献
11. 附录
```

## 项目结项报告变体

```
一、项目背景与目标
二、研究内容与进展
三、核心技术与创新
四、成果与应用
五、团队与条件
六、结语与展望
```

## 各部分字数分配建议

| 部分 | 课程论文 | 项目结项 | 期刊发表 |
|------|---------|---------|---------|
| 问题提出 | 800-1200 | 1000-1500 | 600-1000 |
| 文献基础 | 1500-2500 | 2000-3000 | 1000-2000 |
| 方案展开 | 2000-3000 | 3000-5000 | 1500-2500 |
| 应用场景 | 1500-2500 | 2500-4000 | 1500-2500 |
| 结语 | 500-800 | 800-1200 | 500-800 |
| **总计** | **6000-10000** | **9000-15000** | **5000-9000** |

## 注释格式示例

### 页下注（期刊常用）

```
¹ 作者. 题名[J]. 期刊名, 年, 卷(期): 页码.
² 作者1, 作者2. 题名[M]. 出版地: 出版社, 年.
³ 作者. 题名[EB/OL]. URL. (日期)[访问日期].
```

### 脚注（学位论文常用）

```
① 作者：《书名》，出版社年份，第X页。
② 同上。
③ 参见XXX：《书名》，第X-XX页。
```

## 引用标注位置

| 场景 | 标注位置 | 示例 |
|------|---------|------|
| 引用观点 | 句末右上角 | 促进了...¹ |
| 引用原文 | 冒号后 | 如所述："..."² |
| 综合论述 | 句末 | 形成共识...³⁴ |

## 常见问题

### Q: 结构和篇幅如何平衡？
A: 核心章节（方案展开+应用场景）应占总篇幅50%以上

### Q: 文献综述如何不堆砌？
A: 按主题分类述评，每类3-5篇文献，最后总结研究空白

### Q: 如何体现创新性？
A: 在文献述评中明确指出"现有研究存在xxx不足，本研究提出xxx"
